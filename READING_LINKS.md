- Fabric dimensional modeling overview: https://learn.microsoft.com/en-us/fabric/data-warehouse/dimensional-modeling-overview

- Kimball dimensional modeling techniques: https://www.kimballgroup.com/data-warehouse-business-intelligence-resources/kimball-techniques/dimensional-modeling-techniques/
- Apache Parquet overview: https://parquet.apache.org/docs/overview/
- Fabric medallion architecture: https://learn.microsoft.com/en-us/fabric/onelake/onelake-medallion-lakehouse-architecture
- SQL Server CDC overview: https://learn.microsoft.com/sql/relational-databases/track-changes/about-change-data-capture-sql-server
- Fabric incremental copy tutorial: https://learn.microsoft.com/en-us/fabric/data-factory/tutorial-incremental-copy-data-warehouse-lakehouse
- Fabric Lakehouse overview: https://learn.microsoft.com/en-us/fabric/data-engineering/lakehouse-overview
