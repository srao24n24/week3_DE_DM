# Week 3 Data Engineering and Dimensional Modeling

This package contains all datasets, starter files and templates needed for six lab days.

## Setup
1. Use Python 3.11 or later.
2. Create and activate a virtual environment.
3. Run `pip install -r requirements.txt`.
4. Keep `provided_data` unchanged. Write your work under a new `work` folder.
5. Read the candidate handbook before starting each day.

SQL Server is recommended for DDL practice but is not required for the design-only labs.
